# 实验二 —— 一次失败的架构对比，和它意外测出的东西

[English](README_en.md) · **中文**

> **这个实验没有做成它打算做的事。** 保留它是因为它测出的东西比原计划更有用，
> 而且下面这个错误值得写下来。

## 原计划

PLDM 是 le-wm 论文对比的 baseline 之一，实现就在 `stable_worldmodel` 包里。
它的类接受和 LeWM 的 JEPA 相同的构造参数，也暴露相同的 `encode()` / `predict()`，
所以只改模型配置里的 `_target_` 路径，就能塞进同一个训练循环和同一个规划器。
打算做的是：固定预算，只换架构，看架构本身有多大影响。

结果：

| | pred_loss | CEM 成功率 | embedding 平均标准差 | 死维度 |
|---|---|---|---|---|
| LeWM h=3 | 0.266 | 52% | 0.325 | 0 / 192 |
| PLDM | 0.298 | 66% | 0.380 | 0 / 192 |

看起来是个漂亮的反例：预测更差、规划更好。**但它不是。**

## 为什么它不成立

**一、这两个"架构"是同一个。**

```bash
$ diff stable_worldmodel/wm/pldm/module.py stable_worldmodel/wm/lewm/module.py
$ echo $?
0
```

逐字节相同。`Predictor`、`Embedder`、`MLP`、`Transformer` 全都一样。
两个主文件 `pldm.py` / `lewm.py` 是 153 对 154 行，差异只在 `rollout()` 的推理优化上
（dtype 处理、embedding 缓存与 detach、动作编码批量化），不涉及模型结构。

所以这从来就不是一次架构对比。

**二、两次运行的随机初始化不同，而且没有种子控制。**

`train.py` 调 `spt.Manager(...)` 时没有传 `seed=` 参数，
而 `Manager` 只在收到这个参数时才调 `pl.seed_everything`——
它甚至会打印一句 `User didn't specify seed, runs won't be exactly reproducible!`。
`cfg.seed` 只被用来构造数据划分的 `torch.Generator`，管不到模型权重初始化。

实证：**训练开始之前**的 sanity-check 验证 loss 就已经不同了——LeWM 5.147，PLDM 5.001。
一步梯度都还没走。初始权重不一样。

**三、14 个百分点在统计上不显著。**

双比例 z 检验（`../../04_analysis/significance.py`）：z = 1.44，p = 0.15，
95% 置信区间 [-5, +33] 个百分点，跨过 0。

## 那它到底测出了什么

**同一个架构、同一份数据、同一套配方、同样 900 步，只有随机初始化不同，
跑出来的差距是：预测 loss 0.266 → 0.298（12%），规划成功率 52% → 66%（14 个百分点）。**

也就是说，这是一次意外的**重跑方差测量**。而这恰恰是这个仓库最需要、
原本却没有的一个数字：**噪声底**。

有了它，其他实验就有了尺子：

| 对比 | 差距 | 相对噪声底 |
|---|---|---|
| h=1 vs h=3 | 2pp | 远在噪声内 |
| h=5 vs h=3 | 12pp | 在噪声内 |
| SIGReg 默认 vs 塌缩 | 18pp | 略高于噪声，仍不显著（p=0.064） |
| 官方 ckpt vs 我的 h=3 | 34pp | 显著（p<0.001） |

结论：**在这套设置下，15 个百分点以内的成功率差距都不能当结论。**
包括我原本想从这个实验里读出来的那个。

## 教训

想做架构对比，光看"构造函数签名一样、能互相替换"是不够的——
得先 `diff` 一下实现。我是在被问到"官方不是说 LeWM 比 PLDM 好吗"之后才去查的，
而那时这个结果已经写进 README 和讲稿了。

另一个教训是：**评估规模要先于实验设计确定。** 50 条 episode 的评估
只能分辨 30 个百分点以上的差距，而我设计的三组实验，预期效应量全都在 10-20 个百分点。
换句话说，就算架构真的不同，这个实验也测不出来。

## 复现

`./run.sh` 会重跑训练和评估。如果你想把它变成一次**真正的**重跑方差测量，
把同一个配置跑 5 次不同 seed 就行——本来就该这么做。
