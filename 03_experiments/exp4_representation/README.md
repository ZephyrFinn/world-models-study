# 实验四 —— 决定规划成败的到底是什么？

[English](README_en.md) · **中文**

> 这一组是前三组的诊断。它不训练任何模型，只在已有的 12 个 checkpoint 上
> 做低方差测量——然后发现**前三组实验测的是同一个混杂变量而不自知**。

## 为什么做这个

前三组实验全部用 CEM 规划成功率当主指标，而那个指标的噪声（±19pp）
比它们的效应量（2–18pp）还大。第一反应是"多跑 seed"，但那只是硬扛噪声。

真正的问题来自论文摘要里两个方向相反的声明：

> SIGReg 把 embedding 逼向**各向同性高斯**——所有方向方差相等、维度间无相关。
>
> "LeWM's latent space encodes meaningful **physical structure** through probing
> of physical quantities."

tworoom 的物理状态本质上是低维的（智能体 xy + 目标 xy）。把它塞进 192 维、
再强迫各向同性，要么破坏几何、要么只是白化、要么靠注入无关维度稀释信号。
**哪一种是经验问题，论文没扫。**

于是换一批指标，全部在 3000 帧留出数据上算，方差远小于 50 条 episode 的成功率：

| 指标 | 含义 |
|---|---|
| `gauss_stat` | Epps-Pulley 正态性统计量——**SIGReg 声称要优化的东西** |
| `probe_r2` | 岭回归 `embedding → 智能体位置` 的留出集 R²——论文的 probing 口径 |
| `eff_rank` | 协方差特征值参与比——实际被用起来的维度数 |
| `emb_mean_std` | 每维标准差的均值——表征的绝对尺度 |

先在已知分布上校准过（`probe_physics.py` 里的 `gauss_stat`）：
真·各向同性高斯 = 0.5，4 维线性流形嵌入 192 维 = 170.6，有效秩还原到 3.93。指标可用。

## 发现一：决定规划成败的是**尺度**，不是表征质量

在 11 个 900 步 checkpoint 上算与成功率的相关：

| 指标 | r | 显著性 |
|---|---|---|
| 物理探针 R²（"信息够不够"） | +0.24 | 不显著 |
| 有效秩 | −0.22 | 不显著 |
| 离高斯距离 | −0.40 | 不显著 |
| **embedding 尺度** | **+0.89** | **t = 5.85，显著** |

![](../../04_analysis/figures/exp4_scale_vs_success.png)

**表征里有多少物理信息，跟能不能规划几乎无关；表征的绝对尺度才是决定性的。**

机制解释：CEM 靠比较 embedding 空间里的距离来选动作。信号尺度缩小而 predictor
的噪声不变，代价地形就被噪声淹没——**规划失败不是因为信息没了，是信噪比崩了。**

这条直接推翻了我在实验三里写的解释。塌缩那个 checkpoint 的探针 R² 是 0.467，
健康的是 0.497——**位置信息几乎完好**。线性探针是尺度不变的，方向结构还在。

## 发现二：前三组实验测的是同一个混杂变量

![](../../04_analysis/figures/exp4_confound.png)

**实验一**：成功率排序 (52, 54, 64) 与尺度排序 (0.319, 0.348, 0.389) 完全一致。
我把 h=5 的 64% 解释成"更多上下文帮助预测"，但"那次初始化恰好给了更大尺度"
解释得一样好——而且后者有 r=0.89 撑腰。

**实验三**：成功率的倒 U (34, 52, 38) 和尺度的倒 U (0.0012, 0.319, 0.116) 同形。
仍然是尺度这一个变量在动。

**实验二**：真正稳定的组间差异一直都在，只是我没看那一列——
PLDM 系统性地把尺度压低约 4 倍（0.074/0.076 对 0.259/0.324/0.401）。
它唯一表现好的那个 seed（62%），尺度恰好跳到 0.307，进入 LeWM 的量级。
**用低方差指标一眼可见的差异，用成功率测了 6 次都没测出来。**

关键是：**加 seed 救不了这些实验**。跑 45 个 seed 只会得到一个混杂量的精确估计。

## 发现三：SIGReg 没在做它声称的事

整个 λ 扫描里 `gauss_stat` 是 **1206 / 1206 / 1206**——权重调 1000 倍，
离高斯的距离纹丝不动。而参照值是：真高斯 0.5，4 维线性流形 170。

也就是说，训出来的表征离各向同性高斯有 **2400 倍**远，比一个 4 维线性流形还远 7 倍，
而且**只用了 192 维里约 4 维**。

这不是模型失败——tworoom 的状态本来就约 4 维，学到紧凑的低维流形正是它该做的。
但这意味着：**SIGReg 实际起的作用是维持 embedding 尺度（0.0012 → 0.319 → 0.116），
不是高斯化。** 论文命名的机制和实际生效的机制不是一回事。

顺带回答了开头那个张力：**两个声明不冲突，因为高斯化根本没发生。**
表征保住了物理结构（R² ≈ 0.5），恰恰是因为它没有被真的各向同性化。

## 发现四：官方 checkpoint 是个说明性的例外

它的尺度只有 0.032（比我所有健康模型小一个量级）、有效秩 1.66（全场最低），
**却拿到 86%**。

说明"尺度决定成败"只在**欠训练**模型里成立。训练充分之后 predictor 的噪声降下来了，
小尺度不再是问题——它学会了一个极度紧凑（1.66 维！）但精确的表征。

**这可能才是"训练充分"的真正含义**：不是表征变大，而是预测精度追上了表征的精细度。
900 步的模型只能靠"把表征撑大"来盖过自己的预测噪声。

## 复现

```bash
./run.sh          # 纯推理，不重新训练，约 15 分钟
```

`results/probe_physics.json` 是全部原始输出。

## 这一组为什么值得单独存在

前三组是"改一个东西，看下游指标"，第四组是"下游指标到底被什么决定"。
后者才回答了为什么前三组测不出东西——**而且它便宜得多**：不用重训，
在已有 checkpoint 上跑一遍推理就够了。

如果重来一次，这应该是**第一组**实验。
